## 🤔 El Problema

Muchas personas no saben:
- 📝 Cómo organizar y guardar sus recetas
- 🧮 Cuánto ingrediente usar cuando cambia el número de personas
- ⏰ Cuánto tiempo realmente toma preparar un plato
- 🛒 Exactamente qué comprar en el mercado sin errores

**Resultado:** Recetas desorganizadas, cálculos inexactos, platos quemados y tiempo perdido.

---

## ✨ La Solución: App Recetas Inteligentes

Una aplicación que piensa por ti:

| 🎯 Función | 📝 Qué hace |
|-----------|-----------|
| 📖 **Biblioteca de Recetas** | Almacena tus recetas favoritas en un solo lugar |
| 🧮 **Ajuste Automático** | Cambia personas → Sistema recalcula ingredientes |
| 🛒 **Lista de Compra** | Genera PDF listo para llevar al mercado |
| ⏱️ **Temporizador Inteligente** | Alertas en cada paso para no quemar nada |
| 💵 **Cálculo de Costos** | Sabe exactamente cuánto cuesta preparar |

### Ejemplo Real:
```
Receta: Fríjoles para 4 personas
- 2 tazas de fríjoles
- 1 cebolla grande
- 3 dientes de ajo

Necesitas 8 personas?
👆 Solo cambia el número

¡El sistema recalcula todo automáticamente!
- 4 tazas de fríjoles
- 2 cebollas grandes
- 6 dientes de ajo
```

## 🏗️ Alcance del Proyecto

### ✅ Incluye
- Registro de usuarios seguro
- Base de datos de recetas (especialmente recetas tradicionales)
- Cálculo automático de porciones e ingredientes
- Generador de lista de compras en PDF
- Temporizador con alertas
- Cálculo de costos estimados

### ❌ NO incluye
- Venta de ingredientes
- Entrega a domicilio
- Integración con supermercados

## 📚 Metodología: SCRUM

¿Por qué SCRUM? Porque igual que cocinar por etapas:
- 🥣 **Etapa 1:** Remojar
- 🔥 **Etapa 2:** Cocción
- 🧂 **Etapa 3:** Sazón

Nuestro proyecto:
- **Sprint 1:** Levantamiento de requisitos (remojar)
- **Sprint 2:** Diseño y desarrollo (cocción)
- **Sprint 3:** Integración y pruebas (sazón)
- **Sprint 4:** Deploy (servir)

Esto permite:
- ✅ Entregas progresivas
- ✅ Ajustes rápidos si "le falta algo"
- ✅ Adaptación a cambios del cliente

```bash

git clone https://github.com/Paisa-ART/app-recetas-inteligentes.git

# Backend
cd src/backend
pip install -r requirements.txt
python manage.py runserver

# Frontend (nueva terminal)
cd src/frontend
npm install
npm start
```
